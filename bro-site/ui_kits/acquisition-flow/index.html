↓ ไม่ (Eligibility)　　　　　　　　　　　　　　　　　　　　　　　↓ ไม่ (Payment)
👤 เคยสมัคร/ชำระเงินแล้ว(Already Paid)แสดงข้อความว่าคุณไม่สามารถรับรางวัล Referral ได้
🎫 ใช้ Day Pass(Day Pass Excluded)แสดงข้อความว่าแพ็ก Day Pass ไม่ร่วมรายการ
🔁 เคยใช้ Referral ไปแล้ว(One Conversion Used)แสดงข้อความว่าคุณเคยใช้สิทธิ์ Referral ไปแล้ว
✕ ชำระเงินไม่สำเร็จ(Payment Failed)แสดงข้อความแนะนำและให้ลองใหม่อีกครั้ง
⏳ ชำระเงินสำเร็จแต่สิทธิ์ยังไม่พร้อม(Entitlement Pending)แสดงข้อความว่ากำลังดำเนินการ กรุณารอสักครู่
📣 แคมเปญนี้สิ้นสุดแล้ว(Campaign Ended)แสดงข้อความว่าแคมเปญนี้สิ้นสุดแล้ว ไม่สามารถรับรางวัลได้
⭐ เกินจำนวน Stamp สูงสุด(Max Stamp Reached)แสดงข้อความว่าคุณสะสมแสตมป์ครบแล้ว ไม่สามารถรับเพิ่มได้
⚠️ บัญชีถูกระงับ(Suspended / Flagged)แสดงข้อความว่าบัญชีถูกทำเครื่องหมายไว้ กรุณาติดต่อ CS
🛠️ ระบบปิดปรับปรุง(Maintenance)แสดงข้อความว่าระบบปิดปรับปรุง กรุณาลองใหม่ภายหลัง
03

Notification — Trigger → Message → User Action

#Trigger (เมื่อไหร่)Message (ข้อความ)ช่องทางUser Actionหมายเหตุ
1 แคมเปญเริ่มต้น
(Campaign Announcement)
 🎮 ชวนเพื่อนเล่น GeForce NOW รับรางวัลไปด้วยกัน! อีเมล · แจ้งเตือน · In-app คลิกดูรายละเอียด / เข้า Dashboard เพื่อชวนเพื่อน ส่งให้ผู้ใช้ที่เข้าเงื่อนไข (ทั้งแบบยืนยันอีเมลแล้วและยังไม่ยืนยัน)
2 เพื่อนชำระเงินสำเร็จ
(Friend Payment Success)
 เพื่อนของคุณชำระเงินสำเร็จแล้ว! คุณได้รับ +X Stamp อีเมล · แจ้งเตือน · In-app เข้า Dashboard เพื่อดู Stamp ที่เพิ่มขึ้น X = จำนวน Stamp ที่ได้รับตามแพ็กเกจ
3 ถึง Milestone
(Milestone Reached)
 🎁 ยินดีด้วย! คุณปลดล็อกรางวัลแล้ว รับรางวัลของคุณได้เลย แจ้งเตือน · In-app เข้า Dashboard เพื่อ Claim รางวัล ส่งเมื่อถึง Milestone 1 / 3 / 6 / 12
4 มอบรางวัลให้ผู้ถูกชวน
(Referred Reward Delivered)
 คุณได้รับรางวัล 10 ชั่วโมง เล่นได้ทันที! อีเมล · แจ้งเตือน · In-app เข้าเกมหรือ Dashboard เพื่อเริ่มเล่น ส่งให้ผู้ถูกชวน เมื่อชำระเงินสำเร็จ
5 มีการยกเลิก / ปรับปรุงสิทธิ์
(Reversal / Support Notice)
 มีการเปลี่ยนแปลงสถานะการรับรางวัล โปรดตรวจสอบรายละเอียด อีเมล · แจ้งเตือน · In-app ตรวจสอบรายละเอียดหรือติดต่อฝ่าย Support กรณีมีการยกเลิกสิทธิ์/ปรับจำนวน Stamp หรือเกิดปัญหาจากระบบ
